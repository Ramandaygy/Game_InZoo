# 🦁 Game InZoo - 2D Interactive Zoo Exploration

![Unity](https://img.shields.io/badge/Engine-Unity_2D-black?style=for-the-badge&logo=unity)
![C#](https://img.shields.io/badge/Language-C%23-blue?style=for-the-badge&logo=csharp)
![Academic Project](https://img.shields.io/badge/Project-Academic-green?style=for-the-badge)

Project game 2D eksplorasi kebun binatang interaktif yang dikembangkan menggunakan **Unity Engine** dan bahasa pemrograman **C#**. Project ini dibuat sebagai tugas mata kuliah Pemrograman Game / Game Development untuk mempelajari konsep dasar pembuatan game 2D, pergerakan karakter, dan interaksi lingkungan.

---

## 🎮 Fitur Utama

- **Eksplorasi Kebun Binatang 2D:** Navigasi karakter pemain di dalam area kebun binatang.
- **Karakter & Animasi Dasar:** Pergerakan 2D (Top-Down / Side-Scrolling) dengan sprite controller dasar.
- **Interaksi Lingkungan:** Menjelajahi berbagai area kandang hewan dan aset lingkungan 2D.

---

## 🛠️ Tech Stack & Tools

- **Game Engine:** Unity (2D Template)
- **Language:** C#
- **Version Control:** Git & GitHub
